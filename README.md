
# Roomi – A Chatbot-Driven Web Application For Room Rental And Housemate Compatibility Profiling

## Project Overview

Roomi is a Final Year Project developed as part of the Bachelor of Computer Science (Honours) programme at Universiti Teknologi MARA (UiTM).

The project aims to support room rental discovery and housemate compatibility profiling through a chatbot-driven web application.

## Project Objectives

1. To design a chatbot-driven web application for room rental and housemate compatibility profiling.

2. To develop a web application that supports conversational lifestyle profiling and housemate compatibility recommendations.

3. To evaluate the functionality and usability of the developed web application.


## Key Features

### 1. User Authentication
User login and authentication using Firebase.

### 2. Conversational Chatbot
A two-way chatbot prototype that allows users to type messages and provide lifestyle preferences.

### 3. Housemate Compatibility Matching
A proposed matching workflow that applies deal-breaker filtering followed by Cosine Similarity to identify potentially compatible housemates.

### 4. Room Rental Discovery
A planned feature to support users in exploring room rental options.

## Technologies and Concepts
- Web Application Development
- Firebase
- Firebase Authentication
- Chatbot Development
- Artificial Intelligence Fundamentals
- Cosine Similarity (proposed matching technique)

Currently under development.
